# RFC 0007：分区表写回和备份

状态：通过
创建日期：2026-07-02
负责人：Beck

## 摘要

实现受保护的恢复计划写回能力，包括强制扇区备份和写后验证。

## 目标

- 将已通过 RFC 0006 校验的恢复计划应用到磁盘或镜像。
- 写入前备份原始扇区。
- 支持从备份恢复。
- 写入后重新读取验证。
- 保留完整操作记录。

## 安全要求

- 写回必须基于有效恢复计划。
- 目标必须与计划身份匹配。
- 已挂载/系统/内置磁盘默认阻止，除非未来专家模式 RFC 改变此规则。
- 用户必须通过输入式确认和原生确认。
- 自动化测试优先使用镜像目标。

## 写入计划

后端应生成 dry-run 计划，包含：

- 目标磁盘；
- 需要读取备份的扇区；
- 需要写入的扇区；
- 分区表类型；
- 计划写入字节的预期哈希；
- 回滚备份路径。

## 验收标准

- 测试可以在临时镜像文件上写入和恢复 MBR/GPT 表。
- 物理磁盘写回只有在目标安全检查通过后才可用。
- 备份恢复能把镜像还原到原始扇区字节。
- 操作日志包含计划、确认、写入结果和验证结果。

## 开放问题

- 备份文件应与恢复计划放在一起，还是存入应用数据目录？
- GPT 写回是否应在一个事务计划中同时更新主表和备份表？
