# RFC 0006：恢复计划构建器

状态：通过
创建日期：2026-07-02
负责人：Beck

## 摘要

增加一个只读工作流，用扫描结果构建分区恢复计划，为后续写回功能做准备。

## 目标

- 允许用户选择发现的分区候选项。
- 在内存中校验建议的 MBR 或 GPT 布局。
- 以 JSON 导出和导入恢复计划。
- 提供 before/after 分区图。

## 非目标

- 不将分区表写入磁盘。
- 不修复引导扇区或文件系统。
- 不恢复文件。

## 计划模型

恢复计划应包含：

- 源磁盘身份和大小；
- 原始分区表摘要；
- 已选择候选项；
- 建议的分区表类型；
- 校验结果；
- 警告和冲突；
- 创建时间和应用版本。

## 校验规则

- 分区不能重叠。
- 分区必须位于磁盘边界内。
- GPT 计划必须预留必要的头和表空间。
- MBR 计划必须符合主分区/逻辑分区约束。
- 文件系统提示不能被当作正确性的证明。

## 验收标准

- 用户无需写权限即可构建并导出计划。
- 非法计划会被拒绝，并返回可执行诊断信息。
- 同一扫描结果生成的计划具有确定性。
- 快照测试覆盖代表性的 MBR 和 GPT 计划。

## 开放问题

- 导入计划是否应绑定磁盘序列号/哈希，以降低误用风险？
- 第一版 UI 是否允许手动编辑 LBA？
