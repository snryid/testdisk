# RFC 0011：镜像制作、SMART 和风险分诊

状态：通过
创建日期：2026-07-02
负责人：Beck

## 摘要

增加磁盘镜像制作、健康检查和风险分诊指引，让用户在尝试高风险恢复操作前优先基于镜像工作。

## 目标

- 从物理磁盘创建原始镜像。
- 校验镜像哈希。
- 支持中断后继续镜像制作。
- 在可用时展示 SMART 或平台健康信号。
- 当风险较高时建议先制作镜像再修复。

## 镜像要求

- 分块读取源。
- 跟踪已复制字节、读取错误和吞吐量。
- 保存镜像元数据和哈希。
- 支持取消和恢复。
- 输出绝不能写入源磁盘。

## 健康信息来源

| 平台 | 健康信息来源 |
|------|--------------|
| macOS | `diskutil`，可选 `smartctl` |
| Linux | `smartctl`、`/sys/block` |
| Windows | WMI / PowerShell，可选 `smartctl` |

## 分诊规则

以下情况 UI 应建议先制作镜像：

- SMART 报告失败或故障前指标；
- 重复出现读取错误；
- 磁盘断连或身份变化；
- 扫描速度异常下降。

## 验收标准

- 可从 fixture 设备或测试文件创建镜像。
- 哈希和读取错误摘要保存为 JSON。
- 中断任务可在验证源和输出后恢复。
- 修复/写入操作前会展示风险警告。
